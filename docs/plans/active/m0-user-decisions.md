1. 先审阅本地图稿；原生 Figma 同步并确认后，再批准启动 M1。
2. 明确接受当前可编辑 SVG 作为本轮 M0 设计输入，并单独批准 M0 技术路线和 M1 启动；Figma 同步继续作为后续设计任务。
