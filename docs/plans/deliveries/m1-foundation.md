# M1 Windows 可运行基线

输入为已批准的 M0 规格、精简 SVG v2.2 及独立存储、视图和 Windows 时钟交付。集成记录保留各源提交，Slint 署名使用仓库首页官方徽章。

- 纯计时模型覆盖专注、短休、长休，默认 25/5/15 分钟，每四轮长休。清醒单调时钟驱动倒计时，启动计数与活动计数差异用于检测睡眠。到期累计时长止于阶段目标，UI 刷新延迟和暂停区间均排除在活动时长账目之外。
- Windows 主窗按所在屏幕物理宽度 10% 计算目标宽度，展开与收起共用该宽度。视图遵循系统主题，默认回退浅色。必要状态和错误使用明确反馈。已启用 Slint Windows 可访问性后端，设置采用草稿和单次提交。
- SQLite 保存活动快照、终结历史、操作事件、UTC/原时区偏移与配置版本。启动既有库、提交终结记录和运行中达到周期且有变更时触发一致性备份，旧历史和有效备份默认保留。JSON 导出使用 `pomodoro.exe --export-json <目标路径>`。

## 实际验证

- Windows MSVC / Rust 1.100.0 / Slint 1.19.0，最终业务源码通过 `cargo fmt --all --check`、`cargo test --locked --all-targets`（17 项）及 `cargo build --locked`。同一存储源码的独立 crate 测试和独立复跑为 8 项通过，额外验证了 junction 指向的管理目录。
- 使用隔离数据目录运行 Windows 调试构建，观察可访问性树中的阶段、剩余时间和按钮名称，实操 Tab 焦点、空格开始、Enter 暂停、继续及重启恢复。复测恢复提示完整显示。单屏抓取的含窗口边框画面，展开与收起均宽 194 px，高度分别为 332 px 和 120 px。
- 临时库读回开始、暂停、继续及中断记录。实际运行导出命令取得可解析 JSON，涵盖历史、事件、配置版本及原时区偏移。样本中的三份备份全部通过 SQLite 完整性检查，启动前后快照保留相应历史。
- 自然到期和模拟睡眠由可控时钟测试覆盖，Windows 原生时钟另有正常采样记录。真实系统睡眠与休眠、Hyper-V、多屏 DPI、屏幕阅读器播报和发布构建资源测试进入后续验收。

## 运行与数据

执行 `cargo run --locked` 启动窗口。`POMODORO_DATA_DIR` 可为测试指定隔离目录，默认数据库存放于 Windows 用户本地应用数据目录的 Pomodoro 子目录。运行 `cargo run --locked -- --export-json .\pomodoro-analysis.json` 可导出一致性快照，该命令打开已有库，并按启动策略自动创建备份。托盘、置顶、单实例、数据清理/还原界面和 CSV 出口作为后续任务交付。
